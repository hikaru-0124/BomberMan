# BOMBER BATTLE (元祖ボンバーマン再現ブラウザ対戦ゲーム)

HTML5 Canvas と Web Audio API を用いて作成された、2〜6人設定の対戦サバイバルゲームです。空き枠はCPUが参加します。
外部ライブラリ・画像・音声ファイルに依存せず、ブラウザ上で軽快かつ高レスポンスに動作します。

---

## 🎮 遊び方 & ルール

- **目的**: 爆弾を設置してブロックを破壊し、アイテムで自キャラを強化しながら、3体のライバルを倒して最後の1人として生き残りましょう！
- **ステージ**: クラシックな 15 × 13 グリッドの**グリーンフィールド**（鮮やかな芝生の市松模様、白い固定コンクリート柱、破壊可能な赤レンガブロック）。
- **制限時間**: 3分間（タイムアップ時は引き分け判定）。

### 🕹️ 操作方法

#### PC（キーボード）
| キー | アクション |
| :--- | :--- |
| **矢印キー (↑ / ↓ / ← / →)** または **W / A / S / D** | キャラクターの移動（滑らかな角アシスト機能付き） |
| **スペースキー (SPACE)** または **ENTER** / **J** | 爆弾設置 |
| **スペースキー (SPACE)** | ゲームオーバー後のリスタート |

#### スマートフォン・タブレット（タッチ操作）
- 画面下に表示される仮想D-Pad（十字キー）で移動、赤い「BOMB」ボタンで爆弾を設置できます。

## 🤖 登場キャラクター（CPU思考ルーチン）

1. **1P 白ボン (あなた)**: おなじみのヒーロー白ボン
2. **CPU 1 黒ボン (ブラック)**: 好戦的な性格。隙あらばプレイヤーに接近して爆弾を仕掛けてきます。
3. **CPU 2 赤ボン (レッド)**: バランス重視。アイテム収集とブロック破壊を堅実に行います。
4. **CPU 3 黄ボン (イエロー)**: 慎重派。危険感知能力が高く、身の安全を優先して立ち回ります。

※ 全CPUはBFS（幅優先探索）による危険マス判定を搭載しており、自爆を避ける退避ルートがある場合のみ爆弾を設置します。

## 🚀 起動方法

```bash
# 初回のみ依存パッケージをインストール
npm install
# 通信対戦サーバーを起動
npm start
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。
通信対戦にはこのNode.jsサーバーが必要です。Pythonの簡易HTTPサーバーでは通信対戦できません。

### 友達と通信対戦

GitHub Codespacesでは「ポート」タブの8000番をPublicにし、表示されたURLを共有します。
自分が「オンライン通信対戦」→「新しい部屋を作る」を選び、表示された4文字の部屋番号を友達に伝えてください。
友達が同じURLから部屋番号を入力して参加したら、ホストが対戦を開始します。
Codespacesやサーバーを停止すると接続できなくなるため、対戦中は起動したままにしてください。
PublicのURLには誰でもアクセスできます。共有を終了する場合はポートをPrivateに戻してください。

自分のPCで起動する場合、同じWi-Fi内の端末からは `http://起動したPCのIPアドレス:8000` に接続できます（ファイアウォールの許可が必要な場合があります）。

### 💣 オンラインのみそボン（復活あり）

オンライン対戦では、脱落した人間プレイヤーが外周から爆弾を投げて参加できます。

- **W A S D**：上・左・下・右へ外周に沿って移動
- **↑ / →**：遠くへ、**↓ / ←**：近くへ投げる距離を調整
- **SPACE / ENTER / J / BOMB**：黄色い照準のマスへ投げる（赤い照準の壁・ブロック・爆弾のマスには投げられません）
- スマートフォンは十字キーの左右で外周移動、上下で飛距離調整、BOMBで投擲できます。
- 投擲は2秒間隔、火力は2マス。爆弾は飛んで着地してから導火線が進みます。
- みそボンの爆弾・その誘爆で相手（CPUを含む）を倒すと、相手のいた位置で復活します。
- 復活時は基本能力に戻り、2秒間無敵になります。同じ脱落中に投げた古い爆弾で、次の脱落から再度復活することはできません。
- 生存者が1人になるか制限時間が終了すると試合終了です。CPU自身はみそボンになりません。

回帰テストは `npm test` で実行できます。

### ⬡ ヘキサゴン・アリーナ（6人対戦）

六角形の境界と6つの開始地点を持つ、21×17マスの大型ステージです。紫の結晶ブロックを壊しながら戦います。初期選択はこのステージで、最大6人まで同じ部屋に参加できます。

### 対戦人数の設定

部屋を作る前に画面上部の「対戦人数」で2〜6人を選べます。選んだ人数がその試合の参加枠になり、人間プレイヤーが不足する枠はCPUが補充します。部屋を作成した後は定員を変更できません。

### ❄ 氷のアリーナ

画面上部の「ステージ」で「氷のアリーナ」を選択できます。ひとりプレイでもオンラインでも利用できます。
オンラインの待機中はホストが選択し、参加者には同じステージが表示されます。

氷床と結晶ブロックのステージで、中央の縦横に最初から開いた十字通路があります。
四隅のブロック配置は左右・上下対称で、従来のグリーンフィールドにも切り替えられます。
